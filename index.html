    Good to know

    • Signed PDFs: any change invalidates a digital signature. Folio shows a banner and asks before your first edit. Downloading without changes keeps the original signed file.
    • Edit text changes one line at a time in the original font when possible. Hindi and other Indian scripts (Unicode) can be edited and typed as real, searchable text. Scanned pages, invisible OCR layers, outlined or rotated text, Arabic/Hebrew/Thai lines can't be edited; use White-out + Text instead. Hindi lines whose copied text doesn't match the print, and old Kruti Dev/Chanakya lines, are checked first: Folio reads the printed line (it downloads a small text reader once) and asks you to confirm its reading when it isn't sure.

    Edit a signed document?

    This PDF carries a digital signature. Any change — adding annotations, rotating, deleting, reordering or adding pages, or editing text — will invalidate the signature in the file you download. PDF readers will then show it as broken or altered.

    Downloading without making any changes keeps the original signed file intact.
